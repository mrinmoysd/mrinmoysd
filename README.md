## 👋 About me

I'm a senior engineer who has spent a decade shipping real systems — enterprise platforms, consumer mobile apps, AI products, asset management systems. I lead architecture, write a lot of TypeScript, and care about the unglamorous parts of engineering that make products actually work in production.

These days I'm focused on the intersection of **AI engineering and production systems** — building things where LLMs, RAG, and real-time pipelines do real work, not demoware.

I'm strong across the full stack but my sweet spots are:

- **React / Next.js / React Native** with TypeScript
- **Node.js / Express / NestJS** with Prisma and Postgres
- **Azure** (App Service, Blob, Synapse, Key Vault, managed identity)
- **AI engineering** (RAG, embeddings, vector DBs, streaming LLMs, MCP)
